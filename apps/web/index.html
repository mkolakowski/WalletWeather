Import transactions from CSV

Upload a CSV from your bank (or paste text). We'll auto-detect columns, preview the rows, and let you skip duplicates before committing. Optional Category and Tags columns are supported. A row with a Frequency value (Monthly / Weekly / Biweekly) is recorded as a real transaction and linked to a recurring template — give every past occurrence of a bill the same Frequency + Description (or the same optional Recurring Group value, if the description text varies month to month) and they'll all link to one template instead of importing as unrelated one-off charges. Importing more months of the same bill later reuses that template automatically. Not sure of the format? Download a starter template.

Instance branding

Rename the app. Shown in the browser tab, the login screen, and the header. Leave blank and hit Reset to restore the default.

Two-factor sign-in

Require every user who signs in with a password to set up two-factor sign-in. Until they do, they see only the set-up screen, and their API tokens and the iPhone app wait too. Users who sign in only with Google aren't asked: Google has its own two-step check.

Bank sync

Let users bring transactions in from their bank through SimpleFIN Bridge (a service each of them subscribes to), Teller or Plaid. Teller and Plaid are offered only once their keys are in .env. With it on, this server calls the provider for the users who connect; nothing is sent for anyone else. Switching it off stops connecting and syncing; connections already made stay until their users disconnect.

Email alerts

Let users bring in transactions from their bank's alert emails, read from one folder of their Microsoft mailbox (read-only). With it on, this server calls Microsoft for the users who connect; nothing is sent for anyone else. Switching it off stops connecting and checking; connections already made stay until their users disconnect.

User management

View and manage all registered users. Disable users to block login without deleting their data. Deleting a user permanently removes their accounts, transactions, and categories.

Auto-tag rules

When a transaction's description contains the pattern (case-insensitive substring match), the chosen tag is auto-attached on save and on CSV import. Add an optional category filter to scope the rule. Use Backfill to apply every active rule to your existing transactions retroactively.

API tokens

A token lets a script or app use WalletWeather as you, sent as Authorization: Bearer <token>. Read-only tokens can only look; full access can change anything you can, except the Admin panel; admin also reaches the Admin panel, while you're an admin. No token can make or revoke tokens. Revoke one you no longer use, or that may have leaked.
